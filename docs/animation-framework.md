# 高跟鞋人物移动测试

使用提供的 Jill GLB 模型，保留人物、头发、鞋子和材质，添加三个可循环的骨骼动画：

| 动画 | 时长 | 用途 |
| --- | --- | --- |
| `Idle_Heels` | 3.60 秒 | 待机与轻微呼吸 |
| `Walk_Heels` | 1.17 秒 | 来自 `Female Walk.fbx`，适配高跟鞋 |
| `Run_Heels` | 0.66 秒 | 跑步，参考速度 2.40 m/s |

动画为原地循环动画。位置移动由框架处理，步频随实际速度变化，避免根运动重复叠加。
走路已替换为提供的 `Female Walk.fbx`：摆臂、髋部摆动、躯干与手部姿态来自该动作，去掉持续向前位移，保留周期中的重心变化。待机和跑步动画沿用原版本。
新动作适配后的参考步幅为 1.344 米、原速约 1.152 m/s。框架维持走路最大速度 0.95 m/s，并按实际速度调整步频；动画周期与跑步以左脚落地相位对齐。

## 操作

- 手机：左下摇杆移动；摇杆离中心越远，移动越快。右侧拖动画面旋转镜头。
- 点击「跑步」切换跑步/走路；「脚部视角」查看高跟鞋落地；「重置」回到原点。
- 电脑：WASD 或方向键移动，按住 Shift 跑步；拖动画面旋转镜头，滚轮调节远近。
- 摇杆有 10% 死区，斜向移动限速；松开后减速停止。切换应用和失去焦点时清除输入。

## 运行源码

不需要安装网页依赖，也不依赖外部 CDN。Three.js 0.180.0 与加载器已附带。

```bash
python -m http.server 8080 --directory web
```

浏览器打开 `http://localhost:8080`。使用 HTTP 服务访问，直接双击 HTML 不能可靠加载模块和 GLB。
手机访问电脑的局域网 IP，例如 `http://192.168.1.10:8080`；电脑与手机需连接同一网络。
该地址仅为运行示例，按电脑的实际 IP 替换。

## 框架文件

- `web/app.js`：Three.js 场景、摇杆、镜头、动画混合、鞋底接触修正。
- `web/movement.js`：纯移动控制器、速度、加减速、转向与步态相位。
- `web/assets/jill-heels-locomotion.glb`：完整模型及三段可直接播放的动画。
- `scripts/bake_locomotion.py`：从原始模型烘焙动画，需 Python、numpy、scipy、Pillow。
- `scripts/check_movement.mjs`：移动逻辑检查。
- `scripts/check_animation.py`：鞋底顶点、循环闭合与头部同步检查，另需 matplotlib。
- `scripts/retarget_walk.py`：将新走路动作适配至现有模型，仅替换 `Walk_Heels`。
- `scripts/source/female-walk-source.json`：从提供的 FBX 提取的骨骼与动作轨迹，不包含源角色网格或贴图。

## 高跟鞋处理与验证

使用双骨骼 IK 解算髋、膝、踝，保留鞋子在绑定姿态中的脚型；缩短走路步幅，抬脚时保持鞋底离地，支撑末期抬起鞋跟。鞋子不采用赤脚式趾关节弯曲。
原模型头部和头发使用独立骨架，动画同步对应的身体变换。网页切换动画时，以实际鞋底顶点进行轻微高度修正，减轻混合造成的穿地。
为兼容网页蒙皮，将两组共八个权重中最大的四个保留并重新归一化；贴图缩小和压缩，原始几何网格保持不变。

已通过 glTF 格式验证（0 个错误、0 个警告）、三个动画的循环闭合检查、头部骨架同步检查和移动逻辑检查。
单独动画的鞋底最大穿地小于 1 mm；动画混合时网页进行高度修正。
标准桌面网页图形与手机真机的画面、触感和帧率仍需实际测试。当前是平地移动框架，不含台阶、复杂地形、角色碰撞或跳跃。
