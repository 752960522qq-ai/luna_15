# Luna 城市生活 V1 修改报告

本版将移动测试接通为离线生活游戏：主菜单 → 出生公寓 → 城市 → NPC 对话与接任务 → 服装店 → 获得/购买服装 → 返回公寓并领取奖励 → 保存 → 重新打开恢复。

## 主要新增文件

- `web/player-state.js`：唯一持久玩家状态。
- `web/life-data.js`：地点、商品、装束、任务和 8 个 NPC 数据。
- `web/game-systems.js`：时间、任务、交易、衣柜和双槽存档。
- `web/storage.js`：Android 原生持久存储适配、浏览器存储与旧存档迁移。
- `web/interaction.js`：统一区域/距离交互接口。
- `web/navigation.js`：障碍、导航点网络、路径搜索及路径线段检查。
- `web/npcs.js`：共享模型克隆、NPC 状态机、距离更新和对话。
- `web/avatar.js`：两个主角版本、四动画混合、脚底接地与测试服装。
- `web/world-props.js`：安全屋、互动标记、路灯。
- `web/controls.js`：摇杆/镜头/操作按钮独立多指与键盘控制。
- `web/touch-buttons.js`：菜单/弹窗触摸释放触发、拖动取消和兼容 click 去重；保留鼠标与键盘。
- `web/game-ui.js`：菜单、HUD、商店、任务、衣柜、对话、二维地图。
- `web/assets/jill-high-heels.glb`：独立原鞋对，单 mesh、不含身体或骨架，保留原材质。
- `models/jill-barefoot-locomotion.glb.gz`、`barefoot-manifest.json`、`life-assets-manifest.json`：默认主角派生资源与校验。
- `scripts/prepare_life_assets.py`：从只读原模型重建主角动画、纹理优化及独立鞋提取。
- `scripts/check_life.mjs`、`check_life_browser.mjs`：业务/存档/导航/蒙皮和真实浏览器流程测试。
- `scripts/render_heels.mjs`：实际鞋 GLB 三视角预览，不使用生成图替代模型。

## 已知问题与后续边界

- 新服装是简化测试网格，局部裁剪和贴合尚不如正式服装模型；已有高跟鞋/人物资源完整保留。没有物理布料，复杂瞄准或极端混合姿态仍可能发生衣物与手臂穿插。
- 默认赤脚模型仍复用当前高跟鞋动作，保留原骨架与步幅。脚底采样防穿透，但尚无完整脚部 IK 或专用赤脚步态；步行贴地情况以实机观察为准。
- 任务角色固定岗位，另外 4 名市民漫游；无完整日程、角色间物理避让、动态道路封锁或复杂 NavMesh。
- 城市和安全屋采用建筑/家具包围盒阻挡；不是逐三角碰撞，不含复杂楼梯、跳跃、攀爬或大量室内。安全屋为独立测试室，不是现有建筑的精细内部。
- 瞄准仅有姿态和肩后镜头，不含武器射击；Vehicle/weapon 字段与互动扩展点预留，未加入驾驶、交通、警察、通缉、帮派、联机和大规模战斗。
- APK 内置原城市、两个人物版本和完整已准备的男性 NPC 资源，安装包和内存仍有优化空间。低性能设备可选「流畅」；不能把模拟器检查当作真机帧率保证。
- 存档只在本机，卸载/清数据会删除。覆盖原移动测试 APK 后用「新的生活」创建 V1 存档；旧版没有本版任务存档。
