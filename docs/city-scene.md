# 城市场景

已将用户提供的 `ccity_building_set_1.glb` 接入现有摇杆测试框架。本次只更新场景与预览，不生成 APK。

## 尺寸与落脚点

本轮按用户指定比例，将首轮城市整体缩至 **0.45 倍**。人物维持原网格与动画尺寸，静止身高约 1.73 米，包含高跟鞋；人物碰撞半径仍为 0.26 米。
街区路面范围从 558 × 234 米变为 **251.1 × 105.3 米**；最高建筑自身高度约 14.25 米。
归档 GLB 的源单位换算仍为 0.01 米；运行时城市根节点再乘 0.45，最终每源单位对应 0.0045 米。人物单独加载，城市缩放不会作用于人物。

车辆沿用首轮的独立 0.55 校正，本轮再随建筑、道路、路灯和球场一起整体乘 0.45。车辆保持原停车位置与路面接触关系。
其余街区建筑、路灯、道路、球场及贴图保持来源素材的相对比例；该素材是风格化场景，不代表实测城市。

起点位于中间南北街道，源坐标为 `[-14300, 0, -8800]`，重置后朝北。
沥青路面统一至 Y = 0，人行道高差同步缩至 0.09 米。逐帧在世界坐标中采样实际道路网格的地面高度，再叠加原先的高跟鞋蒙皮顶点高度修正，防止悬空或穿地。当前可对齐道路与人行道，不含复杂楼梯攀爬动画。

## 移动与镜头

采用同步乘 0.45 的街区矩形边界和 22 个建筑/车辆包围盒，保持几何外轮廓与碰撞范围一致。
人物在墙边可滑动，无法穿过建筑外轮廓；停止前进时步频根据实际移动距离停止。
建筑碰撞较保守，覆盖屋檐、阳台等外轮廓，当前不支持进入室内。

第三人称距离从 3.5 米缩至 **2.2 米**，缩短约 37.1%；滚轮距离为 1.4–4.1 米。
镜头目标高度由 1.02 米降至 0.9 米，垂直视野从 43° 微调为 46°，为近景中的头顶和鞋跟留出边距；墙体仍会缩短镜头距离以减少穿墙。
日光照明、天空色与远景雾适配街区；镜头远裁剪扩大到 900 米。
四个现有动作及走路/跑步速度保持原配置。

## 资源与验证

1,357 个静态绘制单元按原材质合并为 22 个，保留 31,050 个三角形与 12 张原始 PNG 贴图。
归档 GLB 由 `models/city-neighborhood.glb.gz` 无损还原，校验信息和首轮坐标见 `models/city-manifest.json`；本轮运行比例为 `web/city.js` 的 `CITY_SCALE = 0.45`，归档贴图与网格保持不变。
原上传文件未改写；导入脚本 `scripts/import_city.py` 可用原始 GLB 重新生成派生资源，需要 numpy。

```bash
python3 scripts/prepare_assets.py
python3 scripts/check_web.py
node scripts/check_movement.mjs
node scripts/check_runtime.mjs
node scripts/check_city.mjs
```

`check_city.mjs` 实际加载场景，检查米制边界、开放街道起点、墙体阻挡、墙边滑动、长距离移动与镜头遮挡。
本轮主要预览由实际 Three.js 默认 2.2 米第三人称镜头渲染。开发诊断参数提供单独的俯视截图，正常游戏视角使用同一默认配置。
`scripts/preview_city.mjs` 使用 Playwright 截取街景与俯视图，并实际操作键盘和按钮检查走路、跑步及瞄准待机；需安装 Playwright 与 Chromium。`PREVIEW_OUTPUT` 可指定截图目录，`CHROMIUM_EXECUTABLE` 可指定现有浏览器。
